# Showcase media

Pipelines from the owner's own recordings to showcase videos / pictures (S12 README showcase). Source recordings stay
outside the repo (`~/Videos/`); outputs go to `~/Videos/showcase/` until the showcase picks them.


- `hirefresh.py SRC.MOV [--small]` — the high-refresh video from a 180 fps camera recording of a 144 Hz monitor (stock 60 → Auto 144 → 240 vsync off; the same mouse routine in each). Two three-way wipe sections, real time then slow motion: each clip plays the same stretch of the routine pause to pause (aligned by picture matching), wipes run in the pauses with both sides playing, behind a white divider. It closes on the owner’s own Display Settings visits (Frame Rate stock → Auto; VSYNC off, → 240) at 1/2 speed instead of an end card. `--small` = a 2-pass copy under 19 MB (`hirefresh_60_small.mp4`).
- `hirefresh.py SRC.MOV --cut long [--small]` — the uncut recording in real time (menus included, the mode labelled while the game is on screen), then the slow-motion three-way wipe → `hirefresh_long_60.mp4`. Both cuts carry the colour grade (`GRADE`: the phone footage is underexposed).
- `showcase.py CLIPS_DIR HIREFRESH.MOV MUSIC.wav` — the showcase video (about 1 minute): title menu, widescreen live, Display Settings, the slow-motion high-refresh wipe (hirefresh.py's section), free camera, first person, the Wardrobe page + presets in the shop (2× inset), the developer overlay, end plate over gameplay. Captions are Pillow plates over the footage (no cards on black); music = the user's own `bgm/open.wav`. Output `showcase_1080p60.mp4` (YouTube) + `showcase_readme.mp4` (720p60, 2-pass, under 19 MB).
- `video/` — the clips: a tool mod (`plan.lua`: taps, Lua, animations, clips by tick) run on the Windows box by the loader's `tools/win_steam.py … --mods …,video --encode 60`: one BMP per tick (the game runs as slow as the disk; the clip stays 60 fps), encoded there to near-lossless mkv. `plan_overlay.lua` + `--grab N --alttab 5` records the overlay in real time off the desktop (its fps line must be the display's); cut the overlay stretch to `CLIPS_DIR/overlay_rt.mkv` and delete the grab (it shows the desktop before the game is in front).
